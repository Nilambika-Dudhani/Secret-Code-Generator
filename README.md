# 🔐 Secret Code Generator

## 📖 Overview

Secret Code Generator is a Python command-line application that implements the Caesar Cipher encryption technique. The program allows users to encode plain text messages into secret codes and decode encrypted messages back to their original form using a user-defined shift value.

This project demonstrates fundamental cryptography concepts while showcasing Python programming skills such as functions, loops, conditional statements, string manipulation, and ASCII character operations.

---

## ✨ Features

* 🔒 Encode messages using Caesar Cipher
* 🔓 Decode encrypted messages
* 🔢 User-defined shift values
* 🔠 Supports both uppercase and lowercase letters
* 📝 Preserves spaces, numbers, and special characters
* 🎯 Menu-driven user interface
* ♻️ Continuous execution until user exits

## 🔍 How the Program Works

### Encoding Process

1. User selects **Encode Message**.
2. User enters a message and shift value.
3. Each alphabetic character is shifted forward by the specified number of positions.
4. The encrypted message is displayed.

### Decoding Process

1. User selects **Decode Message**.
2. User enters the encoded message and shift value.
3. Each alphabetic character is shifted backward by the specified number of positions.
4. The original message is displayed.

### Exit Process

The user can terminate the application by selecting the Exit option from the menu.
